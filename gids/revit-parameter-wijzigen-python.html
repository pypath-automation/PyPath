Revit-parameters lezen en wijzigen met Python (met Transaction)

Parameters zijn de gegevens van je model. Zo lees je ze, zo vul je ze in bulk in, en dit zijn de valkuilen waardoor Set niets doet of een fout geeft.

5 min lezen·Bijgewerkt op 10 oktober 2026·Gecontroleerd tegen de Revit API 2025-documentatie

Kort antwoord: haal een parameter op met element.get_Parameter(BuiltInParameter...) (of LookupParameter("naam") voor eigen parameters), lees hem met AsString(), AsDouble(), AsInteger() of AsValueString(), en wijzig hem met Set(waarde). Wijzigen mag alleen binnen een Transaction; in pyRevit schrijf je daarvoor with revit.Transaction("naam"):.

Een parameter ophalen

Er zijn twee manieren:

  • get_Parameter(BuiltInParameter.X) voor parameters die Revit zelf heeft, zoals lengte, diameter, merk, opmerkingen of systeemnaam. De namen staan in de enum BuiltInParameter, bijvoorbeeld CURVE_ELEM_LENGTH, RBS_PIPE_DIAMETER_PARAM, ALL_MODEL_MARK en ALL_MODEL_INSTANCE_COMMENTS.
  • LookupParameter("naam") voor parameters die jullie zelf hebben toegevoegd: projectparameters en shared parameters.

Weet je niet hoe een parameter in de API heet? Klik het element aan met de gratis add-in RevitLookup en kijk bij de parameters.

Waarom LookupParameter breekt in een Nederlandse Revit

LookupParameter zoekt op de naam die je in Revit ziet. Die hangt af van de taal van Revit: wat in een Engelse Revit "Length" heet, heet in een Nederlandse Revit "Lengte". Een script met LookupParameter("Length") werkt dan bij de ene collega wel en bij de andere niet. Gebruik voor ingebouwde parameters daarom altijd get_Parameter met een BuiltInParameter: die naam is in elke taal hetzelfde.

Een waarde lezen

Een parameter heeft een opslagtype (StorageType): tekst, kommagetal, geheel getal of een verwijzing naar een ander element. Daar hoort de leesfunctie bij:

  • AsDouble() geeft het getal in de interne eenheid van Revit: voet. 0,131 voet is 40 mm.
  • AsValueString() geeft de tekst zoals Revit hem toont, met de eenheden van het project. Handig voor een lijst, niet om mee te rekenen.
  • AsString() is voor tekstparameters, AsInteger() voor gehele getallen en ja/nee, AsElementId() voor verwijzingen.

Valkuilen

Set geeft geen fout, maar False

Geef je een waarde van het verkeerde type, dan doet Set niets en geeft False. Een klassieker: een geheel getal op een parameter met kommagetallen.

Controleer daarom de uitkomst van Set, zoals in het voorbeeld met de opmerkingen hierboven.

Alleen-lezen parameters

Sommige parameters rekent Revit zelf uit, zoals de systeemnaam van een leiding. IsReadOnly is dan True, en Set geeft een fout: The parameter is read-only. Kijk dus eerst naar IsReadOnly.

Typeparameters

Een deel van de gegevens zit niet op het element, maar op zijn type. Het type haal je op met doc.GetElement(element.GetTypeId()). Wijzig je een typeparameter, dan verandert hij voor alle elementen van dat type. Doe dat dus bewust.

Eenheden

Lengtes en diameters staan intern in voet. Reken om met UnitUtils.ConvertToInternalUnits en UnitUtils.ConvertFromInternalUnits, met bijvoorbeeld UnitTypeId.Millimeters.

Wat er precies gebeurt als je de transaction vergeet, lees je in "Attempt to modify the model outside of transaction".
